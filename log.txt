# 8. COMPUTE amount_safe_to_pay DETERMINISTICALLY

Definition:

The maximum amount that can safely be paid on request_date before optional spending changes, while satisfying the full safety forecast.

Do not ask an LLM for this number.

A useful formulation is:

    slack[d] = baseline_balance[d] - minimum_balance

For an immediate payment, the payment reduces all subsequent balances.

Thus the safe amount is conceptually bounded by the minimum future slack.

Always enforce:

    0 <= amount_safe_to_pay <= requested_amount

Verify with the simulator rather than relying only on a shortcut formula.

If monetary precision or event ordering makes direct calculation risky, use binary search or deterministic search combined with the simulator.
